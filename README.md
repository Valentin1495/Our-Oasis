# our-oasis

Apps in Toss 프로젝트입니다.

## 오아시스 완성 규칙

- 팀의 하루 공동 달성률이 75%를 넘으면 오늘의 오아시스가 완성됩니다.
- 모든 팀원이 그날 최소 한 번 참여하면 특별 캐릭터가 찾아옵니다.
- 7일 중 5일 이상 오늘의 오아시스를 완성하면 최종 오아시스를 얻습니다.

## 시작하기

```bash
npm run dev
```

## 배포하기

- 앱인토스 배포 API 키는 [앱인토스 콘솔](https://apps-in-toss.toss.im/) > 워크스페이스 > API 키 > 콘솔 API 키 에서 발급받을 수 있어요.

```bash
npm run build
npm run deploy
```
